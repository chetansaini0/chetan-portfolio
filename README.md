# Chetan Saini — Portfolio

Personal portfolio for AI web development & SaaS freelance work.

## Stack

Next.js 15 · TypeScript · Tailwind CSS v4 · Fraunces + Manrope

## Run locally

```bash
cd "chetan portfolio"
npm install
npm run dev
```

Open http://localhost:3000
